  - **発光モデル→透過モデル**。光学的厚み tau を積算し最後に一度だけ色へ写す。

    全域を滑らかに補間すると全部中間色に溶けてエアブラシ画になる。
  - 寒色側を純青 0.58 → ティール 0.50。
  - 本体外側に解析的な淡いオーラ（レイと原点の最近接距離から算出）。

  フェーズ1 残差詰め（2026-08-09 夜。上のフェーズ1に「方向はOK」を貰った後の続き）:

  **計測を先に立てた。** 見た目の議論が主観で往復していたので、判定を数値にした。
  - 本体を「暗部 / 彩度のある中間帯 / 淡部」に分けた面積比を測る。
    参考3フレームの実測は **20.7 / 62.4 / 16.8%**。これを目標値として扱う。
  - 幾何を変えたら必ず tau の CDF を測り直してからランプの停止点を置く。
    tau はシェーダから R チャンネルへ直接書き出せば正確に読める
    （aether のキャンバスはトーンマップを通っていない。診断色 0.5 が 128 で出ることで確認）。
  - 形状はモーフし、シードはロードごとに変わるので、**1枚では測れない**。
    複数シード×複数フレームの平均で見る。

  やったこと:
  - **膜を3層に**（半径比 1.0 / 0.82 / 0.63）。1枚だとレイの貫通が最大2回で
    tau が2値にしかならず帯が積層しない。半径比を 0.72/0.48 のように内側へ寄せると、
    6枚とも貫くレイが半径 0.48 の投影内にしか無く、ボイドが小さな鉤爪状になる。
  - **色相は tau ではなく lateral が担当**。以前は「淡→中間→暗」の中間帯を
    寒暖の左右分割で作っていたが、参考は 5.8 秒でほぼ全面が橙、3.0 秒で青が優勢。
    つまり中間帯の**色相だけ**が場所と時間で振れている。tau に直列で並べると
    等高線状のリングになって似ない。
  - **寒色→暖色は HSV で色相を回す**。ティールと橙はほぼ補色なので RGB 直線補間は
    必ず濁った黄土色を通る。淡色経由にすると塊が乳白色に洗われる。
    参考の実測は #4f4689 → #994f82 → #fca46f で**洋紅を経由**している＝色相環を回っている。
    回す向きは増加側に固定（減少側は緑・黄を通ってまた濁る）。
  - **背景色を参考の実測 #d4e8e1 に合わせ、ランプの pale を同一色にした。**
    縁が背景へ溶けるのは alpha ではなく色の一致で作る。
  - **alpha を色より先に立て切る**（smoothstep 0→0.20 を 0→0.07 に）。
    両方を tau で駆動していたため、ランプのクリーム区間が常に alpha 0.3 前後にあり、
    「淡い領域」が薄い背景としてしか出ていなかった。参考の広いクリームの暈はこれで出る。
  - **露出の正規化**（後述）。
  - MESH_SCALE 1.7 → 2.0（参考は塊が画面の7割を占める）。

  再生中の検証で見つけて直した欠陥（無音だけ見ていたら出ない）:
  - **蓄積が飽和した曲の終盤で塊が黒く潰れた**（暗部 46%。無音時 18%）。
    uShell / uMajor / uAbsorption が同時に tau を押し上げる二重計上だった。
    3つとも係数を下げた。
  - **シードだけで露出が狂っていた**。tau は膜厚（uShell）と縁の甘さ（uSoftness）に
    ほぼ比例するのに densityRamp の停止点は絶対値。シードは baseShell を
    0.048〜0.066 に振るだけだが、それで暗部面積が **15%〜42%** まで暴れていた
    （＝曲によっては真っ黒な塊になる）。uAbsorption に
    `0.110 / (uShell + uSoftness)` の正規化を入れて打ち消し、
    意図した変調（蓄積・キック）だけをランプ上の移動として残した。

  結果（無音・シード4例の平均）: **19.6 / 66.9 / 13.5%**（参考 20.7 / 62.4 / 16.8%）。
  比較画像: docs/aether-progress/phase1b-compare.png（上段=参考3フレーム 下段=現状3例）

  残っている差:
  - 参考の遷移はもっと柔らかい。青と橙の境目が今も帯として見え、線に近い所がある。
  - ボイドが参考の丸い腎臓形に対して、まだ鉤状で角が残る。
  - 参考の下部にある細い縞（膜を横から見た層）が出ていない。
  - 橙が黄土寄りに見えるのは天候・時刻の hueShift（実行時 22時台の夜シフト）が
    乗っているためで、これは意図した色の個性。参考フレームにはこの色味が無いだけ。

  性能: **aether 6.3fps / vita 5.5fps**（ヘッドレス／ソフトウェアレンダ。3回平均）。
  多層化で SDF が常にどこかの膜に近くなり空間スキップが効きにくくなったため、
  以前の「vita の2.2倍速い」から **1.15倍** に余裕が縮んだ。まだ出荷中の vita より
  速いが、実機 GPU での確認は依然として未実施。

  確認してほしい点:
  - **再生前／無音**で、参考に近い光の塊・暗いボイド・縁の溶けになっているか
  - 残差（上記4点）のうち、どれを優先して詰めるか
  - 音を入れたあと細枝や粒状に崩れないか（実機で要確認）
