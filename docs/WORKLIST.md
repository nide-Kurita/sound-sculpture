# Sound Sculpture — やってほしいリスト

エージェントは [worklist-workflow](../.cursor/rules/worklist-workflow.mdc) に従い、このリストを進める。  
前提ルールは [.cursor/rules/project-principles.mdc](../.cursor/rules/project-principles.mdc) に書く。

**運用**

- 優先度 `P1`（高）→ `P2` → `P3`（低）。無いときは **簡単なものから**。
- ユーザーが **OK** と言った項目は **削除**する。
- 1 項目 = 1 まとまり。必要なら `notes` で補足。
- **`ease` はエージェントが判断する**（ユーザーが書く必要はない）。着手後に難しかったら `medium` / `hard` へ上げてよい。
- チャットで進めるときは **「ワークリスト進めて」** でよい。

---

## フォーマット例（コピー用）

ユーザーはタイトルと notes（任意）だけでよい。`ease` はエージェントが追記・更新する。

```markdown
### [P2] 短いタイトル
- status: todo
- ease: easy   # エージェント記入。後から変更可
- notes:
```
