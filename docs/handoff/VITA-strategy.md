## 1. 北（2026-08-24 ユーザー確定。課題より優先）

### 完成後に見てほしい順位（数字が小さいほど強い）

1. **これは彫刻作品だ**（1位）
1. **これはこの曲の痕跡だ**（同率1位）
3. これは宝石／鉱物だ（2位）
4. これは今日この場所で作られたものだ — 天気・時間（3位）
5. これは生き物だ（4位・最下位。無いよりはあるが、完成後の第一印象の主役ではない）

迷ったら「彫刻作品」と「この曲の痕跡」を守る。

### たとえ

vita ≒ **粘土の生命 ＋ 鉱物**。「深海の生命体」だけでは足りない。
LIVE 中は軟体動物（イカ・タコ）のような滑らかな動きをしながら、
彫刻である粘土の上に鉱物を生やし、音の軌跡を作り上げる。

### 今数週間の主戦場

**再生中の生き物としての面白い反応を先に直す。**
仮説: 面白い反応 = 面白い結果、完成形と繋がるはず。
「完成形の種類だけ先に広げる」は主戦場にしない。
※これは作業順の話。完成後の第一印象の順位（生き物は下位）とは別レイヤ。

### 色・膜の方針（北）

- 色: 晴れ＝琥珀、嵐＝硫黄のような**天気の意味の一致を優先**。少し汚くても
  「その天気」である考え方は残すが、**基本は澄んだ綺麗さを前提**にする（濁った現状は未達）。
  Lab 彩度や振れ幅ゲインの係数いじりだけで閉じない。
- 膜: まだ定義を固定しない。**生き物の皮膚ではない**ことは確定。
  澄んだ透明の水のような膜が、結晶になったり粘液になるのはあり。

## 4. 優先順と依存（なぜこの順か）

### 段A: LIVE の反応語彙（主戦場）

#### A0 — 診断（実装より先。コードは読み出し追加まで）

1. **反応語彙の棚卸し表**を作る: いま解析が検出しているイベント（キック／スネア／
   ハット／chugOnset／句頭／melodyFocus／centroid…）× それぞれの視覚反応（何が・
   どう動くか・時間波形）の対応表。「アルゴリズムに対して反映が薄い」を
   **(a) 検出しているのに表示先が無い** と **(b) 表示しているが読めない** に切り分ける。
2. **歌モノ 2〜3 曲**（I'm Yours / ロビンソン / 修羅場）でボーカル句のタイムスタンプを
   人手で数カ所控え、その瞬間に解析が何を出しているかを `live_motion_probe.js` /
   `live_trace.js` で記録する。＝「声が見えない」が**検出の欠落か表示の欠落か**を確定する。
3. **before 値を控える**: 打点比（現状 Fury 1.44 / ロビンソン 1.60 / I'm Yours 2.33）、
   飽和率、曲間シルエット差（ノイズ床 0.022〜0.027 の 15〜20 倍）。以降の全段のガード。

#### A1 — ボーカル・主旋律チャンネル（親和性の本丸。回答5）

- 目的: 歌モノで「声が見える」。ボーカルは打点（点）ではなく**句頭＋持続（線）**なので、
  既存の打点文法とは別の時間スケールの反応が要る。
- 担い手はプランで決める。原則の vita 具体例では中音＝膜だが、「線・持続」を表現できる
  要素（膜の流れ・光の帯・core の伸び等）の中から、**そのスタイルで一番読み取りやすい要素**
  へ割り当てる（原則の抽象化ルールどおり）。
- **依存**: 担い手が膜になった場合、段B（膜の再定義）と**1つのプランに統合する**。
  膜を2度作り直さないことを優先する。
- **2026-08-24 ユーザー決定（A0 完了後）**: 担い手は
  **「コアを伝わる波」と「膜の光の帯」の両方**（提示3案のうち案3）。
  膜が入ったので上の依存条項が発動し、**A1 と段B は統合プラン**として進める。
  検出側は「主旋律の持続」を曲内正規化前の生帯域から作り直し
  （A0 実測: 密な曲でメロ帯域が 0.91 に飽和し句頭が 0/分）、
  句頭・句中・句尻の3状態を持つ線の信号にする、が合意済みの方向。
  声だけの完全分離はしない（ボーカル＋リードを合わせた主旋律チャンネルとして扱う）。
- **2026-08-25〜28 の 3 巡と、その総括**: 統合プラン詳細は **本書 9章**（合意済み）。
  表示の担い手を 3 回作り直し、3 回とも実機で不合格だった:

  | 巡 | 担い手 | 実機判定 | そのとき出した「真因」 |
  |---|---|---|---|
  | 1（08-25） | コアの波＋膜の加算発光 | 見えない | 打点と同じチャンネルだった |
  | 2（08-26） | 接線流（表面が滑る） | 全く見えない | 運ぶもの（動く模様）が無い |
  | 3（08-28） | 体全体の伸び・撓み | 分からない／**うねって見える** | — |

  **3 巡目の「うねって見える」で本当の真因が割れた。** チャンネルは効いていた
  （動きは知覚されていた）。壊れていたのは**時間構造**で、句頭は 6〜11 回/分 正しく
  検出できているのに、その後のレベル追従が離さず**駆動信号が 95〜97% の時間出っぱなし**
  だった（`phrase_shape.js`）。**この 1 点で 3 巡すべての失敗が説明できる。**
  1・2 巡目で出した「真因」はどちらも誤診で、振幅とチャンネルを 2 回追いかけて外している。

  → 句に**寿命**（attack 0.12 / hold 0.85 / life 2.0 秒）を入れて修正。
  出ている時間 0.97 → 0.30、休み 3% → 70%。担い手は 3 巡目（伸び・撓み）のまま。
  **実機判定 4 巡目待ち。段Bは実機 OK まで書かない。**
  再開の入口は [VITA.md](VITA.md) 8章「いまここ」。

- **この経験からの作法（A2 / A3 / 段B へも効く）**: LIVE の反応が「見えない」と言われたら、
  **振幅とチャンネルを変える前に、駆動信号の duty と休みの長さを測る**
  （`phrase_shape.js`）。持続する反応には必ず**寿命**を持たせる。
  可視性は見せたいものと同じ次元で測る（シルエットなら輝度ではなくシルエットで）。

#### A2 — 反応の種類を増やす（回答2の本丸）

- 目的: 同じ強さの出来事でも「**何の出来事か**」で見た目の**種類**（かたち・時間波形）が
  変わる。回答3の「伝播する波・収縮」はここの語彙候補
  （例: キック＝収縮、句頭＝体を伝わる波。割り当てはプランで合意する）。
- 08-20 の修正で「量・場所」（飽和・局在）は改善済み。今回は**種類の differentiation**。
  振幅は上げない。

#### A3 — 遊泳の地（回答3の後半。段Aの最後）

- 出来事と独立した、滑らかな遊泳のような地の動き。曲の性格（テンポ・激しさ）に追従する。
- **地雷**: 2026-08-19 に「常時うねりに戻さない」と記録されている。回答3-b はこれを
  上書きするが、**旧うねりとの違い（出来事を覆い隠さない・ノイズではなく遊泳）を
  プランで明示**し、ガード（打点比が A0 の before から下がらない）を必須にする。
  実機で「常時うねりの再来」に見えたら即戻す。
- 最後にした理由: 地を先に足すと A1 / A2 の効果測定が濁る。

### 段B: 膜・鉱物（膜を水晶の起因に）

- 膜の再定義: 「生き物の皮膚ではない」「澄んだ透明の水 → 結晶／粘液」。
  ロックは**プラン合意の枠内で**全解除（回答4）。案A（真珠シアン）単体の微調整は打ち切り。
- 鉱物 #4 の次案「膜を水晶の起因にする」（2026-08-24 ユーザー提案）をここで扱う。
  北の「粘土の上に鉱物を生やし、音の軌跡を作り上げる」と同方向。
- **球位相で柱を出そうとしない**（禁止どおり）。膜は core と別ジオメトリなので、
  膜側の形・動き・材質の解釈で「生える」をどこまで表現できるかがプランの中心。
- 段Aの後にする理由: 膜は LIVE の視覚チャンネルでもあるため、段Aで**膜の役割
  （何に反応するか）**が決まってから材質・色を与えるほうが手戻りが無い。
  A1 の担い手が膜なら統合プランにする（上述）。

### 段C: 色の語彙再設計

- 天気の意味（晴れ＝琥珀、嵐＝硫黄）は**維持**。未達は「澄んだ綺麗さ」。
- 確定値も実測＋比較画像つきなら候補（回答7）。無音根拠は禁止のまま。
- 出発点は 08-23 の層別実測（濁りの寄与: 染みの混合／光の色／彩度）。
  Lab 彩度・振れ幅ゲインの続きではなく、語彙（各天気の地・染み・光・海の組）から設計する。
- 段Bの後にする理由: 膜の材質再定義は膜の色を必ず変える。色を先に確定すると二度手間。

### 段D: 後回し（この数週間はやらない）

熟成度の曲長非依存化／完成後の生き物感（呼吸）の判断／core 側の板。

### 作法

- 各段とも **プラン提示 → ユーザー合意 → 実装 → 実測 → 比較画像 → 実機依頼** の順。
- **「見えない」と言われたら、まず駆動信号の時間構造（duty・休み）を測る**（`phrase_shape.js`）。
  振幅・チャンネルを先に変えない。段A1 でこれを 3 回やって 3 回とも外した。
- **可視性は「見せたいもの」と同じ次元で測る。** 輝度差は動いていれば増えるだけで、
  読みやすさの証拠にならない。**ユーザーが「見えない」と言ったものを基準線にした比も証拠にならない。**
- ノブを足したら「調整結果（コピー用）」に必ず載せる（`.cursor/rules/dev-tuning-copy.mdc`）。
- コードを触ったら [VITA.md](VITA.md) の 3章・8章を更新してから終える。
- A/B は同一ロード内。無音で置いた仮値は例外なく弱い側に外れる（実機で確定）。

### 9.3 A1 — 触る関数 / 触らない関数

### 9.4 B — 膜の語彙（ここで固定。実装は A1 検証のあと）

#### 役割分担（A1 で決まったこと）

- 膜の LIVE チャンネルは **主旋律の線（帯）** が本線。中音の打点（スネア／カッティング）は
  既存のフラッシュ・線 `uMelodyLine` のまま。帯とフラッシュは時間波形が違うので同居できる。
- 粒子は高音のまま。A1/B では増やさない。

#### B1 膜の地＝水（材質。色の天気語彙は段Cに残す）

**変える（プラン合意の範囲）:**

- 膜フラグメントの「胴の色」（真珠シアンの塗り、`microTint` / `noiseTint` の常時シアン、
  `color += electricBlue * pearlLive` の常時乗り）を、**薄い水**へ。
  フレネルと glint は残す（煌めきロックの再解釈＝水面のきらめき。消さない）。
- `opacityScale` 1.45 は **このスライスでは動かさない**（下げると膜が消えた過去がある）。
  透けはシェーダの胴を薄くして出す。数値を動かすなら比較画像つきで別合意。
- 真珠白・電気シアンの**芯**は、干渉の薄いハイライトとして残してよい。
  やめるのは「球体が青緑の皮膚に見える胴の塗り」。

**変えない:** 完成後の呼吸グロー、星、`environmentMap`、段Cの天気パレット（琥珀／硫黄）。

#### B2 膜＝水晶の起因（鉱物 #4 の次。柱は出さない）

いま結晶は `syncGemFacets()` が粘土の面を開き、膜は `applyMembraneFacets` と
`GEM_MEMBRANE_FRAGMENT` が後追いで板にする。ユーザーの「膜が起因」は逆順にする:

1. 鉱物軸が高く、主旋律の帯（またはその波源方向）が通っている面から、
   **膜が先に板ガラス化する**（既存 `gGemMask` を、帯の方向で局所的に足す）。
2. その面の下の粘土ファセットを開く（`facetCrystal` / `facetLive`）。
   物語は「水の膜が凍って、下の彫刻に結晶が写る」。
3. 軸 0 の曲は恒等（既存ガード）。

**禁止:** 新しい突起ジオメトリ、球半径の揺らしで柱、群晶コーンの係数だけ上げて柱に見せる。

#### B3 粘液

B1 と同じシェーダの別状態。有機軸が高い／膜ゲインが高い所で、帯の流れを遅くし
アルファを少し上げる。新しいメッシュは足さない。B1 と同時に uniform だけ予約してよい。

### 10.1 何が未達か（再定義）

ユーザー（2026-08-24）:「天気・時刻で**変化はする**が、**どの天気も濁って汚い・イメージに合わない**。」

08-23 の層別実測で判明したこと:

| 染みの補色混合 | +3 | 部分 — 同系色化（2026-08-23） |
| 光の色（青固定） | +1.4 | **済** — `weatherLightTint` |
| 膜・ムラ・映り込み | +1〜3 | 未 — **B1 水膜後に再評価が必要** |

**08-24 以降まだ未達なのは「語彙」** — 振幅（振れ幅 2/3）や Lab 彩度 1.6 だけでは
「晴れ＝琥珀」「嵐＝硫黄」という**意味の一致**にならない。

2026-09-02 baseline（`initial_color_grid.js`、振れ幅 2/3・hueNoise 0.35）:

| 指標 | 値 | 読み |
|---|---|---|
| 画面上の本体色相の幅 | **0.149** | 天気差は出ている |
| 面内ノイズ ± | **0.123** | 環境信号（0.149）に近く、埋もれ寸前 |
| ムラ ÷ 環境 | **0.42** | 数値上は OK だが… |

| 雨 15時 本体 H | **0.579** | 設計 0.66（藍）より**シアン寄り** |

**真因（段C）**: 粘土の vertex 色は天気へ振れ切っているが、**B1 水膜が
`waterClear` 白〜シアンで上書き**し、スクリーン上の読み取り色相が深海の同一性（0.58）
へ引き戻されている。加えて **hueNoise 0.35** が環境幅と同程度で、
「今日の天気の色」より「まだら」が勝つ場面がある。

Lab 彩度をさらに上げるだけでは**澄さは増えない**（白飛びする）。必要なのは
**天気ごとの色のストーリー（語彙）** と **水膜を通した地色の読み取り** の再設計。

### 10.2 設計原則（段C の判断基準）

北（1章）と project-principles を段C 用に具体化:

1. **天気の意味優先** — 晴れ＝琥珀・珊瑚、嵐＝硫黄・銅、雨＝藍、雪＝白磁…
   「少し汚くてもその天気」より、**基本は澄んだ綺麗さ**を先に達成する。
2. **同系色ファミリー** — ground と bloom の色相差 **≤ 0.10**（補色混合を作らない）。
   2 極が遠いと `blendDip` だけでは境目が緑/灰になる（08-23 実測）。
3. **暗部でも色を失わない** — 本体 L 0.32〜0.40 では Lab C が原理的に低い。
   **明度を上げる**のではなく、**彩度の floor** と **光の色の同系化** で救う
   （`envMapIntensity` 0.74 は触らない）。
4. **水膜は透けるが地色を殺さない** — B1 の「澄んだ水」は維持。
   底の粘土色が**薄く透けて**天気が読める（物理: 浅瀬の水は底の色が見える）。
5. **曲色は副次** — `audio-palette` の span は触らない。環境側でバランス。

| カッティング | 膜フラッシュ＋赤道バンプ | 同上 | スネアと同スロット |
| 声の句 | 膜の流れ・帯（A1） | **寿命つき** | A2 の対象外（既に別種） |

**結論:** 差は「場所・コーン幅・スケール軸」だけ。幾何の動詞はほぼ
**「局所の外向きバンプ」1語**。時間の動詞も**「急→指数減衰」1語**。
係数を上げても種類は増えない（原則どおり）。

既存のキック Y 潰れは**全体スケールの縦潰し**であり、戦略が言う
「収縮」（体が内側へ縮む）とは別物。補助としては残してよい。

### 11.3 語彙の割り当て（ここで固定。合意対象）

原則の vita 帯域役割は維持（低→粘土／中→膜・線／高→粒子）。
A2 が足すのは**粘土側の動詞の分化**。

| 出来事 | 種類（動詞） | 時間波形 | 担い手 | 触らない |
|---|---|---|---|---|
| **キック** | **収縮**（体の縦潰れ＝シルエット）→ 戻り | 速い潰れ → やや遅い解放（2相） | `group.scale.y`（径内向きは 1巡で不可視→不採用） | 振幅の天井、声、膜の水 |
| **スネア** | **外向き亀裂**（現状の外向き＋XZ） | 急→速い減衰（現状維持・ sharpen 可） | 粘土外向き ＋ XZ ＋ dust | キックと同じ符号にしない |
| **ハット** | **粒子のチラつき** | 短い寿命 | 粒子を主。上半球の径バンプは**弱める**（種類の純化） | 粒子数の当てずっぽう増やし |
| カッティング | 膜の線・フラッシュ（現状） | 現状 | 膜。粘土のキック収縮と混ぜない | — |
| 声の句 | A1 のまま | 寿命つき | 膜 | **A2 で触らない** |

物語（北との整合）: キックで体が**すっと縮み**、スネアで**弾ける／割れる**、
ハットで**表面がチラつく**。同じ「トゲが伸びる」のバリエーションにしない。

### 11.4 実装スライス

### 11.5 触る関数 / 触らない関数

### 11.6 痕跡（蓄積）への扱い

`liveOffset` → bleed → 永久層。収縮（負）が痕跡に残ると**凹み**になる。
原則「反応の痕跡が最終形に残る」に合う。符号を abs して外向きだけ残すのは**しない**
（また同じトゲ語彙に戻る）。実機で凹みが強すぎたら bleed 係数だけ弱める（種類は維持）。

### 11.7 計測・ガード

| 打点比 core | Fury 1.44 / ロビンソン 1.60 / I'm Yours 2.33 | **下がらない** |
| 種類分布 | （未計測） | キック収縮フレームとスネア外向きが**同時に常時オンにならない**。密な曲でも両方が発火 |
| 飽和 | softCeil 済み | thump/ting の天井張り付きが増えない |
| シルエット差 | ノイズ床の 10×以上 | 維持 |

道具: `live_motion_probe.js`（kind タグ拡張）／`live_strip.js`（キック瞬間の inward を目視）／
`styles_check.js`。

### 11.8 リスク

- **収縮が見えない**: 外向きバンプの残渣が勝っている → thump 正寄与の切り方が甘い。振幅を上げる前に符号分離を疑う
- **常時へこむ**: エンベロープが離さない（A1 と同じ病）→ **寿命必須**。contract は必ず release へ
- **打点比低下**: 内向きはモーション量としては同じでも「見た目のジャンプ」が減る可能性 → probe の hitCoupling 定義が外向き前提なら、絶対変位で測るよう直す
- **声と混ざる**: キック収縮を膜へ載せない（A1 チャンネル分離を守る）

2. スネア＝外向きのまま → **OK**
3. ハット＝粒子主・径バンプ弱め → **OK**
4. 実装順 → 同日実装（A2a+b+c）

### 11.10 実装状態（2026-09-04）

- A2 の本命だったキック／スネアの種類差は**未達**。次案は別動詞が要る（係数では出ない）

## 12. 段A3 — 遊泳の地（詳細プラン・2026-09-04）

### 12.1 目的

### 12.2 診断（なぜ今は地が足りないか）
